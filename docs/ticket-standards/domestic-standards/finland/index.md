# VR

VR uses [SSBv1](../../uic-standards/ssbv1.md) Aztec barcodes, with the following specialties:

* Variable-length alpha-numeric station codes are used, as found [here](https://rata.digitraffic.fi/api/v1/metadata/stations).
* Station codes use an extended alphabet compared to the SSB specification, with letter `Ä` being mapped to the numeric value 63.
* In the past, VR tickets claiming to be SSBv2 have been observed, despite otherwise following the SSBv1 format.
